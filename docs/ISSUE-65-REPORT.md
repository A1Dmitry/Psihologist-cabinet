> Основная реализация #65 влита в `main` через **PR #73** (другой исполнитель, 11:07 UTC).
> Этот PR — дополнение к ней, а не вторая реализация.

## 1. ПЕРВОНАЧАЛЬНАЯ ЦЕЛЬ

DoD #65: генератор .ics (TZID/VTIMEZONE, без второго расчёта длительности), кнопка на
странице успеха рядом с Google-ссылкой, (опционально) та же кнопка в reply/мини-кабинете
клиента, unit-проверки, человекочитаемое имя файла, UTF-8.

## 2. РЕЗУЛЬТАТ

- Генератор, кнопка на странице успеха и кнопка на reply-странице напоминания сделаны
  в PR #73 (`icsEventText` / `icsEventBlob` / `icsEventFileName`, тесты
  `tests/ics-event.mjs` и `tests/ics-success-page.mjs`).
- **Этот PR** добавляет недостающий кусок опционального пункта DoD: кнопку «📅 В календарь»
  у каждой предстоящей встречи в мини-кабинете клиента (`clt_…`, `js/views/cabinetUi.js`).
  Она построена на **каноническом** `icsEventText`, с тем же UID `psyportal-session-{id}`,
  что и на странице успеха, так что повторное скачивание обновляет событие, а не дублирует его.
- Первоначальная версия PR #75 содержала собственный генератор (`buildIcsEvent`). После
  слияния `main` в ветку он конфликтовал с генератором из #73 (`SyntaxError: ICS_PRODID
  already declared`: SPA не загружалась, 13 наборов красные). Собственный генератор и его
  тест удалены, общие файлы приведены к версии `main`.

## 3. ПРОВЕРКА

- `npm run verify`: все 31 набор зелёные, 1408 проверок; `verify_pages.py` против живого
  `devserver.py`: ALL PASS (RRSI-002).
- `tools/verify_cabinet.mjs`: настоящий рендер страницы клиента. Ссылка `data:text/calendar`
  с `download` есть, декодированный .ics содержит `DTSTART;TZID=<пояс кабинета>:<дата/время записи>`.
- Негативный контроль: без кнопки получается `111 PASS / 1 FAIL`; после восстановления зелёное.
- Браузерный смоук (headless Chromium, мок Supabase): SPA грузится без `pageerror`, запись
  доходит до `/booking-done`, кнопка .ics из #73 скачивает файл.

## 4. ПОЛОЖИТЕЛЬНЫЕ РЕЗУЛЬТАТЫ

Один генератор .ics в коде (§6.14). Мини-кабинет импортирует модуль с тем же specifier
(`calendarService.js?v=20260925-ics`), что и `app.js`: один экземпляр модуля, общий cache-bust.

## 5. ОТРИЦАТЕЛЬНЫЕ РЕЗУЛЬТАТЫ

- Кнопка в мини-кабинете не проверена в браузерном E2E: после перезагрузки мок сервера
  перезаписывает локальные записи. Проверена рендером в харнесе.
- Импорт в Apple Calendar/Outlook на устройстве не проверялся.
- CLAIM-комментарий в #65 не опубликован (403). Это и стало причиной дубля (раздел 7).

## 6. ТУФТА НАЙДЕНА

голова PR после «Update branch» (`a63f60b`) была сломана. Merge остановлен, гейт перепрогнан
на фактической голове (§6.15).

  разойтись с реальной (Минск не затронут: там нет DST). Не исправлено, вне этого PR.
