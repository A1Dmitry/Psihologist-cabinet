## 6. Новые находки этого аудита

**F1 (P3, документация) — хрупкие счётчики наборов разошлись снова.**
В `verify.yml` и `tools/verify_all.mjs` был жёстко записан размер гейта:
«24 набора» при фактических 26 (до PR #70), затем «27» при фактических 29 —
ветка отставала от main на 2 набора (их добавили PR #62/#68).
**Действие:** числа убраны из комментариев, вместо них — указатель на источник
истины (`tools/verify_all.mjs`, фактическое число печатает итог прогона).
Так счётчик не может «тихо протухнуть» в третий раз.

**F2 (блокер окружения) — публикация CLAIM-маркера невозможна правами песочницы.**
`gh api repos/.../issues/N/comments` → **HTTP 403** `Resource not accessible by
integration` (создание Issue при этом разрешено). Инструмент ведёт себя честно:
`take` возвращает exit 4 `CLAIM_NOT_PUBLISHED`, `status` показывает такие карточки
как `unpublished` — это описано в `docs/EXECUTOR-CLAIMS.md` §6.
**Действие владельца:** выдать исполнителю `issues: write` (комментарии) либо
работать в режиме `--offline-ok` с фиксацией блокера.
