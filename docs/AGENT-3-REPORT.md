## Как проверялось

Автоматический самоконтроль (не входит в QA-набор Агента 5): `node tools/verify_cabinet.mjs` — **107 PASS / 0 FAIL**. Что покрыто:

1. часовые пояса: конвертация Минск↔Берлин/Токио, переходы дней, смещения, `weekdayOf`;
2. серии: 8 недель = 8 встреч, пропуск занятых слотов, идемпотентность, пауза/возобновление, перенос серии;
3. индивидуальные условия: сохранение в сейфе, автоподстановка цены/валюты/способа оплаты/ссылки в новые встречи, пустое значение снимает условие;
4. T-06: перенос одной встречи (остальные на месте) и перенос всей серии (все будущие — в новом времени);
5. мини-кабинет: токен, отзыв/ротация, состав (`upcoming`/`past`/`materials`/`documents`), «прочитано», «подписано»;
6. запросы клиента: «другое время» → перенос встречи психологом, «постоянное время» → серия, «нужен день» → очередь;
7. статистика: ёмкость недели (45 ч), свободные часы, доход получено/ожидается, разбивка по неделям и месяцам;
8. очередь листа ожидания: пожелание дня/времени/«постоянное время» и создание серии из заявки;
9. рендер всех новых блоков (расписание, книга записей, карточка клиента, статистика, лист ожидания) и страницы клиента;
9b. страница `/reply` по токену напоминания: мини-кабинет клиента + старая карточка ответа (регрессия reply-механизма);
10. разметка `index.html` (все контейнеры на месте, нет дублей id, старые id страницы ответа сохранены);
11. импорт и boot `js/app.js` целиком («IMPORT OK / BOOT RAN»).

Плюс регрессия Агента 1: `node verify_app.mjs` (IMPORT OK / BOOT RAN), `verify_auth.mjs` (25 PASS), `verify_profile.mjs` (29 PASS), `verify_telegram.mjs` (57 PASS), `verify_pages.py` 11/11 при `python3 devserver.py 8899`.

Ручная проверка «глазами» в браузере не проводилась: в песочнице нет headless-браузера, а локальный сервер поднимается (`python3 devserver.py`) — если нужен визуальный прогон, откройте `/cabinet` и `/reply?reply=<токен>`.
