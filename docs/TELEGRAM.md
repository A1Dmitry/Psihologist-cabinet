# Telegram-уведомления — настройка (админ-часть)

> Вход специалиста из Telegram Mini App — отдельный поток; настройка и действия владельца описаны в [`TELEGRAM-MINIAPP-AUTH.md`](./TELEGRAM-MINIAPP-AUTH.md). Он не использует токен бота уведомлений из кабинета.

Уведомления работают через **личного бота психолога**. Токен вводится в кабинете
и хранится на сервере в настройках кабинета (RLS — только владелец). На публичных
страницах токен **не используется и не виден**.

## Что присылается

| Событие | Кому | Выключатель |
|---|---|---|
| Новая запись с сайта | психологу | «Новая запись → вам» |
| Оплата отмечена (кабинет / сайт) | психологу | «Оплаты → вам» |
| Напоминание о сессии (T-24h и второе, по настройкам) | клиенту в Telegram | «Напоминание о сессии → клиенту» |

## Настройка (5 минут)

1. В Telegram у **@BotFather**: `/newbot` → получить токен вида `1234567890:AA…`.
2. Кабинет → вкладка **«Уведомления»** → вставить токен → **«Проверить»** (покажет @username бота).
3. Написать своему боту `/start` в Telegram → в кабинете **«Найти чат»** → выбрать себя.
4. Отметить нужные события → **«Сохранить настройки»**.

## Подключение клиента

Карточка клиента → **«Как подключить»** → отправить клиенту ссылку-приглашение
`https://t.me/<ваш_бот>?start=<clientId>`. Клиент нажимает **Start** → в кабинете
**«Проверить подключения (/start)»** — чат привяжется (колонка «✓ Telegram»).
Напоминания приходят только подключившимся.

## Как доставляется

- **Кабинет открыт** (вкладка/телефон): таймер 60 с отправляет должные напоминания
  и уведомления о новых записях (outbox). Watermark `last_notified_session_at`
  защищает от дублей.
- **Мгновенно с сайта** (пока кабинет закрыт): опционально.
  1. Задеплоить функцию: `supabase functions deploy telegram-notify`
     (папка `supabase/functions/telegram-notify`).
  2. В `js/services/supabaseConfig.js` указать `NOTIFY_WEBHOOK_URL =
     'https://<proj>.supabase.co/functions/v1/telegram-notify'`.
  Токен при этом живёт только в Edge Function (читается сервисным ключом);
  функция двигает watermark, чтобы кабинет не продублировал уведомление.

Свободный текст клиента и результаты опроса в Telegram не пересылаются: уведомление
может сообщить только, что дополнительная информация есть в кабинете. Подробности
смотрите после входа в кабинет.

Без шага «мгновенно» уведомление о записи всё равно дойдёт — при первом же
открытии кабинета (outbox).
